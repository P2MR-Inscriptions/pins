# PINS 1.0.0

PINS (P2MR Inscriptions) 1.0.0 is the first public release of the protocol and its reference tools. It is an application protocol on Qbit's Pay-to-Merkle-Root output. It is not a Qbit or Qbit-Org proposal. The envelope marker is the 4 bytes `pins`.

This note does not create a git tag. The repository is https://github.com/P2MR-Inscriptions/pins.

## What this release contains

- PINS-1 through PINS-6. They specify the envelope, indexing, transfer, metadata, collections, and PSBT trades.
- A reference indexer. It follows a local Qbit node and serves a read-only API on `127.0.0.1`. Two indexers that follow the same chain to the same tip produce the same `stateHash`.
- A reference inscriber. The commands are `keygen`, `address`, `assign`, `plan`, `sign`, `broadcast`, `preflight`, and `price`.
- Mainnet `ACTIVATION_HEIGHT` 161948, the block containing the first `pins` envelope on mainnet. Regtest activation stays 0. PINS-2 does not set a testnet4 activation height.
- PINS-2 vectors TV2-2, TV2-3, and TV2-4 remain open.

## Known limitations

The specifications stay as published. This list copies their open rows. It does not add vectors or change Draft status. It is the list as of this release. The current list is in [docs/specs/README.md](../specs/README.md#open-test-vectors). The version number 1.0.0 belongs to the reference tools. It does not mean that the specifications are final: they are Draft.

- PINS-1 is Draft. TV1-1 through TV1-7 are TODO-regtest.
- PINS-2 records mainnet activation 161948. TV2-1 is computed. TV2-2, TV2-3, and TV2-4 are TODO-regtest. Testnet4 has no activation height.
- PINS-3 is Draft. TV3-1 through TV3-5 are TODO-regtest.
- PINS-4 is Draft. TV4-1 and TV4-2 are TODO-spec. TV4-3 is TODO-regtest.
- PINS-5 is Draft. TV5-1 and TV5-6 are TODO-spec. TV5-3 and TV5-4 are TODO-regtest. TV5-2 is not fixed in that document. TV5-5 and TV5-7 name code in `packages/protocol/reserve.mjs`.
- PINS-6 is Draft. Section 5 marks exact sizes TODO-regtest. TV6-1 through TV6-4 are TODO-regtest. Section 7 also has one TODO-regtest line for a Qbit Wallet sale.

## Install

Clone the repository. The programs are TypeScript run by Node.js 22 with type stripping (`--experimental-strip-types`). That does not work for a package installed under `node_modules`, so PINS is not published to npm.

Node.js 22 is required (`node -v` starts with `v22`). From the checkout: `npm ci`, then `npm run build`, `npm run lint`, `npm run typecheck`, and `npm test`.
