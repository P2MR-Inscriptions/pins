# Code of conduct

This project is the PINS specification and its reference tools. Discussion stays on the protocol, the code, and the chain rules.

## Expected

- Write in specific, technical language. Cite the standard or the file you mean.
- Assume good faith. Disagree with the change, not the person.
- Keep secrets out of issues, pull requests, and chat. That includes keys, seeds, passphrases, and RPC passwords.
- Give credit when you use someone else's measurement or text.

## Not accepted

- Harassment, slurs, or personal attacks.
- Publishing someone else's private key, seed, or credentials.
- Impersonating a maintainer, Qbit, or Qbit-Org. PINS is not an official Qbit proposal.

## Reports

Report conduct that breaks this document through a [GitHub security advisory](https://github.com/P2MR-PINS-Protocol/pins/security/advisories/new) if it involves a secret, and through a maintainer on [the issue tracker](https://github.com/P2MR-PINS-Protocol/pins/issues) otherwise. Maintainers may edit or hide a comment, and may block further participation, when this document is broken.
